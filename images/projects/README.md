# صور المشاريع

ضع صور المشاريع هنا بأسماء واضحة مثل `villa-palm-01.jpg`، ثم عدّل `coverImage` و`images` داخل `data/projects.js`.

- `coverImage`: الصورة التي تظهر على بطاقة المشروع.
- `images`: الصور الإضافية التي تظهر عند فتح المشروع.
- `videos`: روابط فيديوهات المشروع، مثل `images/projects/kitchen-tour.mp4`.
- يمكن استخدام مسار محلي مثل `images/projects/villa-palm-01.jpg`.

الفيديوهات تظهر داخل معرض المشروع مع أزرار التشغيل، وتدعم ملفات `mp4` المحلية. أضف المسار داخل مصفوفة `videos` في نفس المشروع.
